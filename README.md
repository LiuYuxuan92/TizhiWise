## 中文说明

**TizhiWise（知体智评）** 是一个移动端优先的中医体质与痛症健康测评平台。平台围绕九种中医体质模型、结构化痛症问卷、配置化算法、动态健康报告、付费解锁、管理后台和 AI 内容工作流构建，帮助用户了解自身身体状态，并获得以“先进厨房，后进药房”为核心理念的个性化饮食、生活方式与健康参考建议。

> 免责声明：本项目生成的健康内容仅用于健康参考与生活方式建议，不构成医疗诊断、治疗方案或用药建议。

### 核心能力

- **双通道测评**：支持体质测评与痛症测评两类入口。
- **体质判定算法**：基于九种中医体质模型，计算原始分、转化分、主体质与兼夹体质。
- **配置版本化**：题库、算法配置、报告模板、AI Agent 工作流均可版本化发布。
- **会话快照**：测评开始时锁定题库与算法版本，保证历史结果可追溯、可复现。
- **动态报告**：根据测评结果组装基础报告与深度报告，并支持付费解锁模型。
- **数据安全**：提供 AES-256-GCM 应用层加密工具与敏感字段转换器。
- **后台与运营扩展**：为题库、算法、报告模板、内容草稿和运营看板预留管理能力。
- **AI 内容工作流**：面向小红书、视频号、朋友圈等渠道的多 Agent 内容生产设计。

- Node.js >= 20
- pnpm >= 10
- PostgreSQL 与 Redis（本地开发可按 `.env.example` 配置）

```bash

```


根据本地环境修改：

- `DATABASE_URL`
- `REDIS_URL`
- `APP_ENCRYPTION_KEY`
- `JWT_SECRET`
- 微信授权 / 微信支付 / LLM Provider 相关变量

```bash

# 单元与属性测试
pnpm test:unit

# 集成测试基座检查
pnpm test:integration

# 代码检查
pnpm lint
```

## English

**TizhiWise** is a mobile-first Traditional Chinese Medicine (TCM) constitution and pain assessment platform. It is built around the nine-body-constitution model, structured pain questionnaires, configurable algorithms, dynamic wellness reports, paid report unlocks, an admin console, and AI-assisted content workflows. The product helps users understand their body patterns and receive personalized food-first lifestyle guidance based on the principle of “kitchen first, medicine only when necessary.”

> Disclaimer: The wellness content generated by this project is for health reference and lifestyle guidance only. It is not a medical diagnosis, treatment plan, or medication recommendation.

### Key Features

- **Dual assessment channels**: constitution assessment and pain assessment.
- **TCM constitution algorithm**: computes raw scores, converted scores, primary constitution, and concurrent constitutions.
- **Versioned configuration**: question banks, algorithm settings, report templates, and AI Agent workflows can be published as immutable versions.
- **Session snapshots**: question-bank and algorithm versions are locked when an assessment starts, making historical results traceable and reproducible.
- **Dynamic reports**: assembles basic and deep wellness reports based on assessment results, with support for paid unlocks.
- **Data security**: includes AES-256-GCM application-layer encryption and reusable encrypted-field transformers.
- **Admin and operations ready**: designed for managing question banks, algorithms, report templates, content drafts, and analytics.
- **AI content workflow**: designed for multi-Agent marketing content generation for Xiaohongshu, WeChat Channels, and WeChat Moments.
